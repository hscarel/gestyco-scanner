📷 GestyCo · Lector

Centrá las barras verticales dentro del recuadro verde. Mantené el código quieto, bien iluminado y a unos 15–25 cm para que enfoque. La lectura es continua: no hace falta sacar fotos.

Tocá «Activar cámara» para comenzar.
El lector usa el detector nativo del navegador cuando existe y, si no, la biblioteca ZXing con un lector local de respaldo. Si no accede a la cámara, probá «Usar cámara del teléfono» o escribí el número. La lectura solo devuelve el código a GestyCo; no modifica el stock.
